# Spec Delta

## Purpose

定義記者可以透過圖形介面維護上市櫃關注公司，並將既有設定安全匯入，以供重大訊息、違約揭露及畫面標示共同使用。

## ADDED Requirements

### Requirement: 使用者可管理關注公司
系統 SHALL 允許使用者新增、編輯、啟用、停用與移除關注公司，並保存股票代號、公司名稱、市場及選填備註或分類。

#### Scenario: 新增有效公司
- **WHEN** 使用者輸入可辨識的上市或上櫃股票代號並儲存
- **THEN** 系統保存該公司並立即將其套用至後續監控

#### Scenario: 輸入無效代號
- **WHEN** 使用者輸入無法由目前公司名錄辨識的股票代號
- **THEN** 系統拒絕儲存並顯示可理解的驗證訊息

### Requirement: 停用不刪除歷史
系統 MUST 在停用或移除關注公司後保留已收集的歷史訊息與工作紀錄。

#### Scenario: 停用公司
- **WHEN** 使用者停用某關注公司
- **THEN** 系統停止以該公司作為重大訊息篩選條件，但歷史資料仍可查閱

### Requirement: 可匯入既有股票清單
系統 SHALL 在首次設定時支援從既有 `config/default.json` 匯入股票代號，並避免重複建立相同市場與代號的公司。

#### Scenario: 匯入含重複代號的設定
- **WHEN** 使用者選擇匯入且清單包含已存在的公司
- **THEN** 系統只新增缺少的公司並回報新增、略過與失敗數量
