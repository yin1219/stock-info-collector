# Spec Delta

## Purpose

定義每日全市場違約交割揭露的擷取、資料日期確認、延後重試與關注公司標示，避免將來源尚未更新誤判成市場沒有資料。

## ADDED Requirements

### Requirement: 每日檢查上市櫃全市場資料
系統 SHALL 每日查詢上市與上櫃官方違約交割揭露，並保存揭露日期、公司、券商、金額及來源提供的其他欄位。

#### Scenario: 官方揭露多家公司
- **WHEN** 每日檢查取得有效且為目標日期的全市場資料
- **THEN** 系統保存各筆資料並更新該市場的最後成功日期

### Requirement: 關注公司在全市場清單中突出顯示
系統 SHALL 以目前關注清單比對違約交割資料，且不因公司未被關注而省略市場紀錄。

#### Scenario: 結果包含關注公司
- **WHEN** 全市場結果中有啟用關注公司的股票代號
- **THEN** 系統在列表、摘要與通知內容中為該公司加上關注標示

### Requirement: 區分無資料、尚未更新與來源失敗
系統 MUST 根據來源回應、資料日期及解析結果分別呈現「本日無揭露」、「官方尚未更新」與「檢查失敗」。

#### Scenario: 18:30 仍是舊日期
- **WHEN** 預定檢查成功連線但官方資料日期早於目標日期
- **THEN** 系統標記為尚未更新，預設安排 19:00 重試且不發送無違約通知

#### Scenario: 有效回應明確顯示零筆
- **WHEN** 官方來源已更新至目標日期且結果為零筆
- **THEN** 系統記錄本日無揭露並將工作標記為成功

#### Scenario: 來源無法取得或解析
- **WHEN** 上市或上櫃任一必要來源發生連線或格式錯誤
- **THEN** 系統標記受影響市場為失敗並保留另一市場的獨立結果
